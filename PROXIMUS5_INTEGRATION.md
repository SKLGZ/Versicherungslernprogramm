# PROXIMUS 5 Integration

## Overview

This application now includes **complete integration** of the PROXIMUS 5 reference material (1407 pages) for IHK insurance exam preparation according to §34d GewO.

## What's Integrated

### Complete Reference Material
- **Total Pages**: 1407
- **Publisher**: Berufsbildungswerk der Deutschen Versicherungswirtschaft (BWV) e.V.
- **Year**: 2026
- **File**: `1128_ePub.pdf`

### All Sections Covered

1. **Hausrat/Glas** (Pages 43-189)
   - VHB 2021, AGlB 2021
   - Tarife, Unterversicherung, Elementarschäden

2. **Wohngebäude** (Pages 190-339)
   - VGB 2021 Privat, Wert 1914, Gleitender Neuwert
   - Versicherungssumme 1914 Berechnung

3. **Haftpflicht** (Pages 340-489)
   - AVB Haftpflicht 2021
   - Versicherungssummen, Schadenregulierung

4. **Kraftfahrt** (Pages 490-699)
   - AKB 2021
   - SF-Klassen, Typklassen, Regionalklassen Tabellen
   - Prämienberechnungen

5. **Rechtsschutz** (Pages 700-799)
   - ARB 2021, Bausteine, Wartezeiten

6. **Leben** (Pages 800-1049)
   - Basisrente, Riester, Fondsgebunden, Risikoleben, BU
   - Schichtenmodell, Steuerliche Behandlung
   - Alle Tarife (S10-S35)

7. **Unfall** (Pages 1050-1149)
   - AUB 2022, Gliedertaxe, Progression

8. **Kranken** (Pages 1150-1299)
   - MB/KK 2009, MB/KT 2009, MB/PPV 2022
   - Basistarif, Standardtarif, Altersrückstellungen

9. **Reise** (Pages 1300-1349)
   - AT-Reise 2021, Reiserücktritt, Reiseabbruch

10. **Finanzanlagen** (Pages 1350-1407)
    - PROXIMUS Fonds (Bond, Global, Balance, Strategic, etc.)

## How It Works

### AI Context Enhancement
The application's AI has been enhanced with comprehensive PROXIMUS 5 context including:
- All insurance conditions (Bedingungen)
- All tariff structures (Tarife)
- Complete tables (SF-Klassen, Typ-/Regionalklassen)
- Calculation formulas
- Contract documents

### Features Using PROXIMUS 5

1. **Theory View (Wissensdatenbank)**
   - Generates learning content directly from PROXIMUS 5 sections
   - Cites specific paragraphs and page numbers
   - Uses original definitions and formulations

2. **Quiz View (Prüfungstraining)**
   - Creates questions based on actual PROXIMUS 5 conditions
   - Uses real tariff values and table data
   - Provides explanations with source references

3. **Calculation View (Rechen-Labor)**
   - Generates calculation problems with PROXIMUS 5 tariffs
   - Uses original tables (SF-Klassen, Typklassen, etc.)
   - Shows complete calculation steps with sources

4. **Chat View (Tutor Chat)**
   - AI tutor with full PROXIMUS 5 knowledge
   - Answers questions with exact source citations
   - Provides detailed explanations from the 1407-page reference
